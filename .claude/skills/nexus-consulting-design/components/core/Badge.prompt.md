Compact status / category pill.

```jsx
<Badge tone="success" dot>Operativo</Badge>
<Badge tone="cyan" variant="solid">IA</Badge>
<Badge tone="neutral">Borrador</Badge>
```

Tones: accent / cyan / neutral / success / warning / danger. `variant`: soft (tinted, default) or solid (filled, dark text). `dot` adds a leading status dot that glows in soft variant.
